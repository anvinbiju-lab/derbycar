# Derby Minibus & Cars — premium website

Buildless HTML, CSS and JavaScript. Run `npm run dev` to preview on http://127.0.0.1:4173. Run `npm run check` for JavaScript syntax validation. Deploy the `dist` directory.

Includes responsive cinematic hero, subtle pointer motion, scroll reveals, return journey logic, airport selector, enquiry dialog, email handoff, mobile navigation, FAQ, accessible reduced-motion support, metadata, JSON-LD and sitemap.

The enquiry flow prepares an email; it does not claim to send enquiries or confirm bookings. No third-party form endpoint, analytics, tracking cookies, or database is configured.

Hero image is AI-generated illustrative imagery, visibly disclosed. Replace with verified fleet photography before promoting specific vehicles. Capacity, availability, rates, licensing and policies require business confirmation. Existing Google reviews are linked without asserting a live count. Fonts use Google Fonts with local system fallbacks.

Site metadata currently refers to the private Sites origin. When moving to the business domain, update canonical, OG URLs, JSON-LD, robots and sitemap; map any existing URLs to appropriate pages and preserve redirects. Private hosting does not provide public search indexability.
